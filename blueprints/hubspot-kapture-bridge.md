# Blueprint: HubSpot ↔ Kapture CX Bridge

**Use case:** Travel, Hospitality, and Service-heavy organisations that need booking/customer context to flow into the service desk.

## Pattern
- HubSpot = System of Engagement (sales, marketing, customer record)
- Kapture CX = System of Action (tickets, service workflows)
- Sync key customer and booking fields + lifecycle stage changes

## Critical Success Factors
- Clear field mapping and ownership
- Data quality rules before ticket creation
- Bi-directional updates only where necessary
